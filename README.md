# Luxury Beauty Cosmetics Pop-Up Events Analysis

## Overview
Analyzed 2,133 luxury beauty pop-up events across 5 global regions to identify revenue drivers, sell-through performance, and footfall conversion rates.

## Tools Used
Python, pandas, matplotlib, SQLite, Jupyter Notebook

## Key Findings
- Europe leads all regions with 87.5M USD in total revenue
- High-Street venues have the highest sell-through rate at 74.09%
- Estée Lauder is the top brand with 20.6M USD in revenue
- Mobile Pop-Up Trucks convert foot traffic most efficiently at 3.10%
