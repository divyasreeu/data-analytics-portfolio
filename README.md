### 1. Luxury Beauty Cosmetics Pop-Up Events Analysis
**Tools:** Python, SQL, pandas, matplotlib, Jupyter Notebook  
**Dataset:** 2,133 luxury beauty pop-up events across global retail locations  

**Key Findings:**
- Europe leads all regions with 87.5M USD in total revenue
- High-Street venues have the highest sell-through rate at 74.09%
- Mobile Pop-Up Trucks convert foot traffic most efficiently at 3.10%

### 2. Netflix Customer Churn Analysis
**Tools:** Python, SQL, pandas, seaborn, scikit-learn, Jupyter Notebook  
**Dataset:** 5,000 Netflix customer records with subscription and engagement data  

**Key Findings:**
- Basic plan subscribers churn at 61.83%, nearly 20% higher than Premium users
- Churned customers average only 5.92 watch hours vs 17.45 for retained customers
- Logistic regression model predicts churn with 88.1% accuracy
